# Reflection

Yes, AI helped me a lot with this presentation. I used Claude Code together with
the Slidev framework — the same approach shown at the workshop. AI helped me
structure the story of my project into 14 slides, handled the Slidev layout and
styling, and even wrote an embedded playable mini-version of my Arkanoid game in
JavaScript, so the presentation can be played, not just watched. The content
itself is my real Python/pygame study project: the code on the slides comes from
my repository and the "what I learned" conclusions are mine. I would definitely
use AI for presentations again — it saves hours of formatting work and lets me
focus on the content, and interactive elements (playable demo, animated code
highlighting, clickable navigation) would take me a very long time to build by hand.
The one rule I took away: AI output must be reviewed — I went through every
slide and adjusted the wording myself.
